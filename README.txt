VIRAX — نسخه خالص (نصب تازه) 2.0.0
==================================

این بسته برای نصب از صفر است: بدون دیتابیس، بدون کاربر، بدون پیام و بدون فایل‌های
توسعه (اسکرین‌شات‌ها، لاگ‌ها و ابزارهای آزمایش). نصب‌کننده (install.php) همه چیز را
خودش می‌سازد.

★ 2.0.0 نسخه‌ی پاک و خالص است: صفر الگوی بدافزار-نما، فونت پیش‌فرض دانا،
  و نام فایل‌های وضعیت (JSON) بر اساس کلید نصب ساخته می‌شود تا از مرورگر
  قابل حدس نباشد. جزئیات: DESIGN.md و CHANGELOG-2.0.0.md

پیش‌نیاز
--------
- PHP 8.1 یا بالاتر (با افزونه‌های pdo_mysql، mbstring، curl، openssl)
- MySQL / MariaDB
- Apache یا Nginx (برای آپاچی: mod_rewrite اختیاری)
- Node.js 18+ فقط اگر سرور Realtime را می‌خواهید

مراحل نصب (۴ قدم)
-----------------
1. کل محتوا را در روت وب‌سرور کپی کنید (مثلاً C:/wamp/www/ch).
   مطمئن شوید پوشه‌های data/ و uploads/ قابل نوشتن هستند.
   ⚠ فایل‌های مخفی (.htaccess و web.config) هم باید کپی شوند. اگر از طریق FTP
     آپلود می‌کنید، گزینه‌ی «نمایش فایل‌های مخفی» را روشن کنید.
2. در مرورگر باز کنید:  http://localhost/ch/install.php
3. در فرم نصب وارد کنید:
   - مشخصات دیتابیس (هاست، پورت، نام دیتابیس، کاربر، رمز)
   - نام کاربری و رمز مدیر (ادمین)
   - نام برند سایت
4. دکمه نصب را بزنید. پس از پایان:
   - سایت:       http://localhost/ch/
   - پنل مدیریت: http://localhost/ch/admin.php

پس از نصب
---------
- رمز مدیر به صورت hash (bcrypt) در data/config.php ذخیره می‌شود، نه متن ساده.
- پوشه‌های حساس (data/، data/backups/، websocket/، uploads/) به‌صورت خودکار
  با .htaccess + web.config + index.php محافظت می‌شوند.
- پشتیبان‌ها با AES-256-GCM رمزگذاری می‌شوند و فقط با لینک امضاشده‌ی یک‌بارمصرف
  قابل دریافت‌اند.
- در پنل مدیریت ← کارت «وضعیت امنیت» می‌توانید همه‌ی این‌ها را ببینید.

اگر روی Nginx هستید (مهم)
-------------------------
Nginx فایل .htaccess را نمی‌خواند. فایل nginx-security.conf.example را باز کنید و
بلوک‌های location را داخل server block خود کپی کنید، بعد:

    nginx -t && systemctl reload nginx

بدون این مرحله، data/config.php و data/backups/ روی وب قابل دسترسی‌اند — هرچند
محتوای پشتیبان‌ها رمزگذاری‌شده است و بی‌کلید قابل خواندن نیست.

دستیار هوش مصنوعی (اختیاری)
---------------------------
پنل مدیریت ← کارت «دستیار هوش مصنوعی»:
- آدرس پایه API سازگار با OpenAI + نام مدل + کلید API
- گزینه‌ها: پاسخ در همه گروه‌ها / فعال در پیوی / تعداد تلاش برای هر پیام
- کلمه‌های صدا زدن (پیش‌فرض: ویراکس) یا ریپلای روی پیام دستیار
- فایل data/cacert.pem برای اتصال HTTPS همراه بسته است.

سرور Realtime (اختیاری)
-----------------------
پوشه websocket/ شامل سرور Node است (server.js + package.json):

    cd websocket
    npm install
    node server.js

برای توقف: در همان پنجره Ctrl+C را بزنید.

نکته: فایل‌های .bat (استارت/استاپ/استارت خودکار ویندوز) از این نسخه حذف شدند.
دلیلش این است که فایروال‌ها و آنتی‌ویروس‌ها اسکریپت‌هایی که در پوشه Startup
ویندوز فایل می‌سازند را به‌عنوان «ماندگاری بدافزار» می‌شناسند و کل بسته را قرنطینه
می‌کنند. دو خط دستور بالا همان کار را انجام می‌دهد، بدون هیچ پرچم قرمز.

نکات امنیتی سرور Realtime:
- پیش‌فرض فقط روی 127.0.0.1 گوش می‌دهد. آن را روی اینترنت باز نکنید؛ اگر لازم
  است، پشت یک reverse proxy با TLS بگذارید.
- بدون PUSH_SECRET معتبر بالا نمی‌آید (به‌جای fallback ناامن، اجرا را متوقف می‌کند).
- Origin ها به‌صورت allow-list بررسی می‌شوند؛ «*» پذیرفته نمی‌شود.
- عضویت در اتاق با «تیکت» امضاشده تأیید می‌شود، نه با نام اتاق از سمت کلاینت.

اگر اجرا نشود، چت با long-poll هم کامل کار می‌کند.

ساختار پوشه‌ها
--------------

- fonts/      فونت‌های اصلی (Kalameh)

نکته درباره‌ی آنتی‌ویروس هاست
-----------------------------
اگر هاست شما فایل‌ها را قرنطینه می‌کند، این بسته برای همان حالت بازنویسی شده است.
در نسخه‌ی 1.9.4 عمداً هیچ‌کدام از این‌ها وجود ندارد:

- فایل .bat / .cmd / .ps1 / .exe
- ساخت .htaccess در زمان اجرا توسط PHP
- نوشتن فایل PHP در زمان اجرا (dropper)
- بازنویسی data/config.php از طریق درخواست وب
- رمزگذاری فایل با حذف فایل اصلی (الگوی باج‌افزار)
- کانتینر باینری سفارشی با هدر جادویی
- متغیر متغیر ($$var) و دسترسی داینامیک به $GLOBALS
- eval / assert / base64_decode روی ورودی کاربر
- فایل مستقل download.php

بررسی قبل از آپلود
-------------------
اگر هاست فایل یا ZIP را قرنطینه می‌کند، اول بسته را با اسکنر همراه
(vx_scan.py) چک کنید:

    python vx_scan.py VIRAX-Clean-1.9.4.zip

اگر RESULT: clean بود و باز هم روی هاست حذف شد، مشکل محتوا نیست؛ فیلتر
پسوند یا سیاست هاست است. در آن حالت از tar.gz استفاده کنید یا فایل‌ها را
با FTP (بدون آرشیو) آپلود کنید.

نکته‌ی مهم: اسکریپت پنل حالا در assets/js/admin.js است. اگر فقط admin.php را
آپلود کنید، پنل بدون جاوااسکریپت بالا می‌آید. همیشه کل بسته را کپی کنید.

دانلود پشتیبان از admin.php?download=<token> انجام می‌شود و توکن یک مقدار
تصادفی ۶۴ کاراکتری است که در سشن ادمین ذخیره می‌شود — یک‌بارمصرف و پنج دقیقه معتبر.

نسخه: 2.0.0 — نسخه پاک و خالص.

ابزار تشخیص
-----------
فایل check.php جدا از بسته تحویل داده می‌شود. آن را در ریشه آپلود کنید و باز کنید:

    https://your-site/check.php?k=<کلید>

دقیقاً می‌گوید کدام فایل‌ها روی سرور غایب‌اند. بعد از خواندن حذفش کنید.
