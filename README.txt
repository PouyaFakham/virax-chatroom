VIRAX — نسخه خالص (نصب تازه) 1.8.7
==================================

این بسته برای نصب از صفر است: بدون دیتابیس، بدون کاربر، بدون پیام و بدون فایل‌های
توسعه (اسکرین‌شات‌ها، لاگ‌ها و ابزارهای آزمایش). نصب‌کننده (install.php) همه چیز را
خودش می‌سازد.

پیش‌نیاز
--------
- PHP 8.1 یا بالاتر (با افزونه‌های pdo_mysql، mbstring، curl، openssl)
- MySQL / MariaDB
- Apache یا Nginx (برای آپاچی: mod_rewrite اختیاری)

مراحل نصب (۴ قدم)
-----------------
1. کل محتوا را در روت وب‌سرور کپی کنید (مثلاً C:/wamp/www/ch).
   مطمئن شوید پوشه‌های data/ و uploads/ قابل نوشتن هستند.
2. در مرورگر باز کنید:  http://localhost/ch/install.php
3. در فرم نصب وارد کنید:
   - مشخصات دیتابیس (هاست، پورت، نام دیتابیس، کاربر، رمز)
   - نام کاربری و رمز مدیر (ادمین)
   - نام برند سایت
4. دکمه نصب را بزنید. پس از پایان:
   - سایت:       http://localhost/ch/
   - پنل مدیریت: http://localhost/ch/admin.php

دستیار هوش مصنوعی (اختیاری)
---------------------------
پنل مدیریت ← کارت «دستیار هوش مصنوعی»:
- آدرس پایه API سازگار با OpenAI + نام مدل + کلید API
- گزینه‌ها: پاسخ در همه گروه‌ها / فعال در پیوی / تعداد تلاش برای هر پیام
- کلمه‌های صدا زدن (پیش‌فرض: ویراکس) یا ریپلای روی پیام دستیار
- فایل data/cacert.pem برای اتصال HTTPS همراه بسته است.

سرور Realtime (اختیاری)
-----------------------
پوشه websocket/ شامل سرور Node است (server.js + package.json):
    cd websocket && npm install && node server.js
اگر اجرا نشود، چت با long-poll هم کامل کار می‌کند.

ساختار پوشه‌ها
--------------
- assets/   آیکون‌ها، فونت‌های رابط، CSS/JS برنامه
- fonts/    فونت‌های اصلی (Kalameh)
- icons/    آیکون‌های شبکه‌های اجتماعی فوتر
- data/     تنظیمات نصب و کش امنیتی (بعد از نصب پر می‌شود)
- uploads/  فایل‌های رسانه‌ای کاربران (خالی)
- websocket/ سرور سوکت اختیاری
